# ADR-001 — MVC con Thymeleaf para las pantallas

| Campo | Valor |
|---|---|
| Estado | Aceptado |
| Fecha | 13 de noviembre de 2026 |
| Decisores | Kevin Andréy Flórez Ramírez y Juan Miguel Corales |
| Requisitos | NFR-ZAP-003, NFR-ZAP-006, REQ-ZAP-014 |
| Relacionado | ADR-002, ADR-004 |

## Contexto

La tienda debe usarse desde el navegador de un computador o de un celular, sin instalar una aplicación. El equipo tiene dos personas y tres sprints de una semana. Las pantallas dependen del rol: cada usuario ve un menú y unas acciones distintas. Se necesita entregar rápido, con una sola aplicación y sin mantener dos clientes (web y móvil).

## Decisión

Se usa Spring MVC con vistas Thymeleaf generadas en el servidor y Bootstrap 5 para la adaptación a pantallas. Los controladores devuelven el nombre de la plantilla y el modelo; no se construye una API REST separada ni una SPA.

Consecuencias positivas:

- Una sola base de código y un solo despliegue.
- El rol se resuelve en el servidor con Spring Security y `sec:authorize`, sin exponer lógica de autorización en JavaScript.
- El HTML es accesible y comprobable con MockMvc, lo que facilita las pruebas de los 46 criterios.
- No se necesita un segundo equipo de frontend.

Consecuencias negativas:

- Cada interacción requiere una petición al servidor; no hay actualizaciones parciales sin JavaScript.
- El acoplamiento entre plantilla y modelo es mayor que en una API.
- Las pruebas de vistas deben buscar fragmentos de HTML, lo que es más frágil que probar JSON.

## Alternativas consideradas

1. **React o Angular con API REST.** Mejor interactividad, pero duplica el trabajo y exige mantener dos proyectos en un sprint de una semana. Se descarta.
2. **Aplicación móvil nativa.** Fuera de alcance y con costo de publicación en tiendas. Se descarta.
3. **JSP.** Funciona con Spring, pero Thymeleaf ofrece plantillas naturales, mejor integración con Spring Security y validación de formularios. Se elige Thymeleaf.

## Cumplimiento

- `pom.xml` incluye `spring-boot-starter-thymeleaf` y `thymeleaf-extras-springsecurity6`.
- Las vistas viven en `src/main/resources/templates/`.
- `TiendaVistasTest` renderiza catálogo, detalle, carrito y checkout con MockMvc.
- El diseño es responsive con Bootstrap 5 y CSS propio.
